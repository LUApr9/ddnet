# 三种训练方法对比说明（Scratch / Sup-Mig / Self-Sup）

本文档总结本项目中三种训练方法的区别、适用场景与对比实验注意事项。

## 1. 方法定义

### 1.1 Scratch（从头训练）
- 含义：不加载任何预训练权重，模型随机初始化后直接训练。
- 训练入口：`model_train.py`（或由上层脚本调用 `curriculum_learning_training`）。
- 作用：作为最基础对照组（baseline）。

### 1.2 Sup-Mig（监督迁移预训练）
- 含义：先在有标签源域做监督预训练，再迁移到目标域微调。
- 预训练入口：`pretrain_entry.py`
- 微调入口：`model_train.py` 或 `selfsup_to_ddnet70_finetune.py`（本质都调用 `curriculum_learning_training`）
- 作用：利用源域标签信息，通常收敛更快、精度更高（前提是源域与目标域相关）。

### 1.3 Self-Sup（自监督 MSAE 预训练）
- 含义：先用无标签 seismic 做掩码重建学习表征，再用于目标任务微调。
- 预训练入口：`selfsup_msae_pretrain.py`
- 微调入口：`selfsup_to_ddnet70_finetune.py`
- 当前实现：基于 DDNet70 编码主干（`pre_seis_conv/down3/down4/down5/center`）做掩码重建。

## 2. 三者核心区别

| 维度 | Scratch | Sup-Mig | Self-Sup |
|---|---|---|---|
| 是否用预训练 | 否 | 是 | 是 |
| 预训练监督信号 | 无 | 有标签（vmodel/轮廓） | 无标签（掩码重建） |
| 对标签依赖 | 目标域标签 | 源域+目标域标签 | 仅微调阶段依赖目标域标签 |
| 迁移对象 | 无 | 完整模型权重（常见） | 主要是 DDNet70 编码主干 |
| 典型优势 | 纯基线、公平参照 | 任务一致性高、收敛快 | 可利用大量无标签数据 |
| 典型风险 | 收敛慢、样本效率低 | 受域偏移/标签质量影响 | 下游任务一致性略弱于监督迁移 |

## 3. 本项目中的实际路径与产物

### 3.1 Scratch
- 初始化：`init_model_src=""`
- 训练：`model_train.py -> curriculum_learning_training(...)`
- 输出：按训练流程保存到 `result/...` 下的阶段模型与 loss。

### 3.2 Sup-Mig
- 预训练输出目录：`models_pretrain/<TargetDataset>Model/`
- 常见权重：`DDNet70_... .pkl`
- 微调时：将该 `.pkl` 作为初始化权重传入。

### 3.3 Self-Sup
- 预训练输出目录：`models_pretrain/<TargetDataset>Model/`
- 关键产物：
  - `*_full_msae.pth`：完整 MSAE 权重（含重建头）
  - `*_ddnet70_backbone.pth`：可用于 DDNet70 微调的主干权重
  - `*.pth`（legacy）: 兼容历史流程的全量 MSAE 保存
- 微调脚本：`selfsup_to_ddnet70_finetune.py`
  - `pretrained_load_mode="partial_backbone"` 时会做“部分加载兼容”，并生成 `*_merged_for_finetune.pth` 供后续严格加载。

## 4. 为什么 Self-Sup 要“部分加载兼容”

- DDNet70 微调主流程内部通常按完整 `state_dict` 严格加载。
- 自监督权重往往只覆盖编码主干，不能直接与完整网络键完全一致。
- 因此当前实现会：
  1) 先筛选可匹配主干键；
  2) 与随机初始化模型合并；
  3) 导出可完整加载的 `merged` 权重；
  4) 再进入统一微调流程。

## 5. 对比实验建议（保证公平）

进行 Scratch / Sup-Mig / Self-Sup 对比时，建议固定以下变量：
- 相同 `dataset_name` / `model_type`
- 相同课程学习 epoch 配置（`firststage_epochs/secondstage_epochs/thirdstage_epochs`）
- 相同 `finetune_lr_scale`
- 相同 batch size、随机种子、测试集与评估指标

只改变“初始化来源”这一项：
- Scratch：空权重
- Sup-Mig：监督预训练权重
- Self-Sup：`*_ddnet70_backbone.pth`（或其 merged 结果）

## 6. 适用场景建议

- 数据和标签都充足：优先 Sup-Mig（通常上限更高）。
- 有大量无标签 seismic：Self-Sup 价值明显。
- 需要严格基线：必须保留 Scratch 对照组。
